# apartment-search — как класть критерии пользователя на инструменты

Порядок «от грубого к точному». Не начинай с выкачивания выдачи.

## 1. Разложи запрос

| Сказал пользователь | Куда кладётся |
|---|---|
| снять / купить / посуточно / в лизинг | `deal`: rent / sale / daily / lease |
| квартира, дом, участок, коммерция | `estate` (по умолчанию flat) |
| «Ваке», «Сабуртало», «Старый Тбилиси» | `subdistricts` — принимает и микрорайон, и район |
| «двушка», «2-3 комнаты» | `rooms: [2, 3]` |
| «до 900 долларов» | `price_max: 900`, `currency: "USD"` |
| «до 1500 за метр» | `price_max: 1500`, `price_per_m2: true` |
| «от 60 метров» | `area_min: 60` |
| «с лифтом, с мебелью» | `features: ["elevator", "furniture"]` |
| «что новенького» | `mode: "paged"` + `order: "date_desc"` |

Название района раскрывается во все его микрорайоны автоматически: `subdistricts: ["Ваке-Сабуртало"]`
даст все 13. Если не уверен в названии — сначала `geo(city=...)`.

## 2. Посчитай, прежде чем качать

Вызови `count` с фильтром. Это один дешёвый запрос, и он сразу показывает,
осмысленны ли критерии:

* `cards` < 10 — фильтр слишком узкий, предложи ослабить (расширить район, поднять потолок цены);
* `cards` > 2000 — слишком широкий, добавь ограничений, иначе выдача будет случайной;
* сравни несколько вариантов фильтра между собой, это дёшево.

## 3. Выбери режим и только теперь ищи

* **`mode: "paged"` (по умолчанию)** — когда важна свежесть или пользователь спрашивает
  «что нового». Даёт `published` — реальную дату публикации. ~30 объектов на запрос.
* **`mode: "fast"`** — когда нужен охват: «покажи всё на карте», «какой разброс цен»,
  «сколько вариантов с лифтом». Быстрее в разы, но `published` там `null`.

Не смешивай режимы в одном ответе пользователю: получится смесь датированных и
недатированных объявлений, и разницу никто не заметит.

## 4. Детали — точечно

`listing(application_id)` — по конкретным кандидатам, не по всей выдаче.
Там удобства, координаты, кадастровый код, число просмотров и контакт.

## Что сообщать в ответе

Всегда: сколько объектов показано против `cards`; какая дата у каждого объявления
(или что она неизвестна); что `cards` и `applications` — разные числа.
Никогда не выдавай `bumped` за дату публикации: это платное поднятие, у топовых
объявлений оно почти всегда «сегодня».
